# Bad Mojo Redux

A simple attempt at reverse-engineering the Bad Mojo Redux game.

## Patterns

Currently, there is only one `.hexpat` available:

- [bmj.hexpat](./patterns/bmj.hexpat) - Bad Mojo save file

## Todolist

I plan to reverse engineer other formats used by the game, especially `.mash` files and scribble objects.
Maybe, one day, I will prepare a test data I could check these hexpats against.

At some point, I am going to start working on a save editor, or maybe a whole "modding" environment.
